Thiloka Portfolio Website

How to open in VS Code:
1. Extract the ZIP file.
2. Open the folder named thiloka-portfolio in VS Code.
3. Install the VS Code extension: Live Server.
4. Right-click index.html and select Open with Live Server.

Files:
- index.html: website structure
- style.css: full design and responsive styling
- script.js: menu and scroll animations
- assets/profile.png: your professional photo

To update GitHub projects:
Open index.html and edit the Projects section links/details.
