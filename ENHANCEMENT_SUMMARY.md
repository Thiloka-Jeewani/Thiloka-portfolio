## 🔧 CUSTOMIZATION GUIDE

### Changing Colors
Edit the CSS color values:
```css
Primary Color: #6366f1
Accent Color: #74bcff
Background: #061125
Text: #f5f8ff
```

### Adjusting Animations
Modify timing values in CSS:
```css
transition: all 0.3s ease;  /* Change 0.3s to desired duration */
animation: fadeIn 0.8s;      /* Adjust animation speed */
```

### Modifying Typing Effect
Edit JavaScript roles array:
```javascript
const roles = [
  "Your Role 1",
  "Your Role 2",
  "Your Role 3"
];
```

## 📞 SUPPORT & TROUBLESHOOTING

### Common Issues

**Issue**: Typing effect not working
- Solution: Check if `#typing` element exists in HTML

**Issue**: Scroll animations not triggering
- Solution: Check intersection observer threshold value

**Issue**: Images not loading
- Solution: Verify image paths are correct relative to HTML file

**Issue**: Animations lagging
- Solution: Reduce animation complexity or check GPU acceleration
